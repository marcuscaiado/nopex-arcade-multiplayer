# ⚡ Nopex Arcade 3D 🕹️

> **Full 3D Walkable Synthwave Arcade Hub** — Control your 3D avatar, walk freely across retro neon corridors, approach 20 arcade cabinets, and press `[SPACE]` to play instant 60fps web games!

---

## 🌟 Highlights

- **Walkable Synthwave Fliperama**: Built with **Three.js** featuring neon carpet, atmospheric illumination, glowing signage, and 4 themed zones (Featured Megahits Rotunda, Action Alley, Sports & Casual, Retro Vault).
- **3D Character Controller**: Kawaii astronaut avatar with animated blinking eyes, bouncing walk cycle, WASD/keyboard controls, and mobile virtual joystick.
- **20 Interactive Arcade Cabinets**: Procedural 3D cabinets with backlit marquees, CRT monitors, dual joysticks, six action buttons, and animated attract screens.
- **Seamless Play Experience**: Proximity detection highlights cabinets and brings up a holographic HUD card. Pressing `[SPACE]` plays an authentic coin-drop chime, smoothly zooms the camera into the CRT monitor, and launches the game in a high-performance bezel frame.
- **Quick Teleport System**: Jump directly to any of the 20 cabinets via the top HUD dropdown.

---

## 🕹️ Controls

| Control | Action |
| :--- | :--- |
| **`W` / `↑`** | Move Forward |
| **`S` / `↓`** | Move Backward |
| **`A` / `←`** | Steer Left |
| **`D` / `→`** | Steer Right |
| **`[SPACE]`** | Insert Coin & Play Cabinet (when near) |
| **`[ESC]`** | Exit Game Overlay & Return to Fliperama |
| **Mobile Joystick** | Touch-drag on bottom-left circle |
| **Mobile Action Button** | Tap glowing `JOGAR 🕹️` button |

---

## 🛠️ Tech Stack

- **Three.js** (`^0.182.0`) — 3D Scene graph, lighting, camera lerping, and materials
- **HTML5 Canvas 2D** — Procedural dynamic textures for carpet, visors, CRT screens, and marquees
- **Web Audio API** — Footsteps, cabinet hums, coin insertions, and UI chimes
- **Vite** — High-performance ES module bundler
